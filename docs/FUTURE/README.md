## Relationship to MVP

The Company Management MVP focuses on:
- **Managing multiple entities** (companies, properties)
- **High-level oversight** (financials, compliance, tasks)
- **Accounting team workflows** (month-end close, task automation)

The Operations Modules will provide:
- **Detailed property operations** (inventory, recipes, purchasing)
- **Granular tracking** (batch numbers, lot tracking, waste)
- **Operational workflows** (receiving, counting, transfers)

They complement each other but serve different users and use cases.
